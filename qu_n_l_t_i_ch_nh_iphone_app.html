Cách cài App lên màn hình chính iPhone

Ứng dụng này được thiết kế chuẩn iOS Web App (PWA) — chạy toàn màn hình như app gốc, lưu dữ liệu ngay trên iPhone kể cả khi mất mạng.

  1. Đưa file lên link web miễn phí: Tải file HTML này về máy tính, kéo thả vào Netlify Drop (app.netlify.com/drop) hoặc GitHub Pages để lấy 1 đường link HTTPS cố định.
  2. Mở bằng Safari trên iPhone: Dán đường link đó vào trình duyệt Safari.
  3. Thêm vào Màn hình chính: Bấm nút Chia sẻ (biểu tượng ô vuông có mũi tên lên ở thanh dưới cùng Safari) → cuộn xuống chọn Thêm vào Màn hình chính (Add to Home Screen) → bấm Thêm.
Mẹo bảo vệ dữ liệu: Định kỳ vào mục Thiết lập → Sao lưu JSON để lưu bản dự phòng về iCloud Drive của bạn.
